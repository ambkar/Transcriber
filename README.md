# Транскрибатор

Локальная программа для Mac, которая превращает видео или запись созвона в текст: делает краткое содержание и расшифровку с разделением по спикерам. Всё работает на вашем компьютере, видео и тексты никуда не отправляются.

## Что это и что умеет

Вы загружаете видео, и через некоторое время получаете документ Word (DOCX) с готовым результатом. Программа открывается в браузере как обычный сайт, но работает только на вашем Mac.

Есть два режима работы:

| Режим | Что на входе | Что на выходе |
|---|---|---|
| Видео | Ссылка на YouTube или Rutube либо файл с компьютера | Саммари и расшифровка по спикерам |
| Расшифровка созвона | Файл записи созвона | Саммари и расшифровка по спикерам |

В расшифровке каждая реплика подписана временем и номером спикера: `[00:01:23] Спикер 2: ...`. Если в разговоре прозвучали имена, программа добавляет их в скобках: `Спикер 2 (Мария)`.

## С чем работает

**Ссылки:**
- YouTube: обычные ссылки `youtube.com/watch?v=...` и короткие `youtu.be/...`;
- Rutube: ссылки `rutube.ru/video/...` и встроенные `rutube.ru/play/embed/...`.

**Файлы с компьютера:** видео и аудио почти любого формата, который понимает программа ffmpeg, например `mp4`, `mov`, `mkv`, `webm`, `avi`, `mp3`, `m4a`, `wav`. Исходный файл программа не копирует, не меняет и не удаляет.

**Что не поддерживается:**
- закрытые, приватные и платные видео;
- прямые эфиры, которые ещё идут;
- язык распознавания: только русский (английские слова и термины внутри русской речи распознаются);
- для режима «Расшифровка созвона» ссылки не подходят, нужен файл записи.

## Как это работает

1. **Звук.** Для ссылки программа скачивает звук, для файла достаёт его из видео. Временный аудиофайл лежит в папке `Work/` и удаляется сразу после создания результата.
2. **Кто говорит.** Нейросеть находит в записи отрезки речи и определяет, какому голосу они принадлежат.
3. **Речь в текст.** Модель Whisper превращает каждый отрезок в текст с пунктуацией.
4. **Имена и саммари.** Языковая модель Qwen3 находит имена участников и пишет краткое содержание.
5. **Документ.** Всё собирается в DOCX и показывается на странице. Кнопка «Показать файл» открывает Finder с готовым документом.

Интернет нужен только при первом запуске для скачивания моделей и для загрузки видео по ссылке. Сама расшифровка идёт без интернета.

## Что получается на выходе

Файл `Final/<название видео>.docx` с двумя разделами:
- **1) Саммари** — абзац о том, о чём запись, и список ключевых пунктов;
- **2) Расшифровка** — реплики по спикерам с временем.

Название файла берётся из названия видео по ссылке или из имени вашего файла. Тот же результат показывается на странице программы отдельными блоками.

## Папки

| Папка | Что в ней |
|---|---|
| `Models/` | модели (скачиваются один раз, дальше берутся оттуда) |
| `Work/` | временное аудио (удаляется после создания итогового файла) |
| `Final/` | итоговые DOCX с названием видео |

Папки создаются автоматически при первом запуске.

## Профили моделей

В программе нужно выбрать профиль. Чем мощнее профиль, тем лучше анализ текста, но тем больше он занимает места и памяти.

| Профиль | Распознавание речи | Анализ текста | Скачать | Память |
|---|---|---|---|---|
| Лёгкий | Whisper large-v3-turbo (q4) | Qwen3-4B 4-bit | ~2,7 ГБ | 8-16 ГБ |
| Оптимальный | Whisper large-v3-turbo | Qwen3-14B 4-bit | ~9,5 ГБ | 16 ГБ |
| Мощный | Whisper large-v3-turbo | Qwen3-32B 4-bit | ~19 ГБ | 24 ГБ |

Для Mac с 16 ГБ памяти рекомендуется «Оптимальный». Для разделения голосов во всех профилях используются небольшие модели pyannote segmentation 3.0 и TitaNet small (около 45 МБ).

Модели скачиваются автоматически при первом выборе профиля, без регистрации и без токенов. Если загрузка оборвалась, нажмите «Начать» ещё раз: она продолжится с того же места.

## Что нужно для работы

- Mac с чипом Apple (M1 и новее). На Mac с процессором Intel программа не работает.
- macOS 15 (Sequoia) или новее. Минимум, который нужен библиотеке для расчётов MLX, это macOS 14, но менеджер пакетов Homebrew официально поддерживает версии от 15.
- Оперативная память по таблице профилей выше.
- Свободное место на диске: не меньше 15 ГБ для «Оптимального» профиля, 30 ГБ для «Мощного». Эти цифры приблизительные, с запасом на программы и временные файлы.
- Интернет для установки и первого запуска.

## Установка

Все шаги выполняются в Терминале. Откройте его: нажмите `Cmd + Пробел`, введите «Терминал» и нажмите Enter. Команды копируйте по одной, целиком, и после каждой дожидайтесь, пока команда закончит работу и снова появится строка ввода.

Если на Mac ничего не установлено, выполните шаги по порядку.

### Шаг 1. Homebrew

Homebrew это установщик программ из Терминала. Вставьте команду:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Установщик объяснит, что собирается делать, и попросит нажать Enter и ввести пароль от вашего Mac. При вводе пароля символы на экране не показываются, это нормально. Если macOS предложит установить «инструменты командной строки», согласитесь и дождитесь окончания.

В конце установки выполните три команды, чтобы Терминал нашёл `brew`:

```bash
echo >> ~/.zprofile
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"
```

Проверьте: команда `brew --version` должна показать версию.

### Шаг 2. ffmpeg и deno

ffmpeg достаёт звук из видео, deno нужен для скачивания с YouTube.

```bash
brew install ffmpeg deno
```

### Шаг 3. Python 3.13.5

Скачайте установщик с официального сайта python.org и установите его:

```bash
curl -L -o ~/Downloads/python-3.13.5-macos11.pkg https://www.python.org/ftp/python/3.13.5/python-3.13.5-macos11.pkg
sudo installer -pkg ~/Downloads/python-3.13.5-macos11.pkg -target /
rm ~/Downloads/python-3.13.5-macos11.pkg
```

Проверьте установку, команда должна написать `Python 3.13.5`:

```bash
/Library/Frameworks/Python.framework/Versions/3.13/bin/python3.13 --version
```

Менеджер пакетов pip устанавливается вместе с Python.

### Шаг 4. Скачивание проекта

Важно: проект нужно хранить в папке `~/Projects/transcriber`, а не на Рабочем столе, в Документах или в iCloud Drive. Иначе macOS может «выгрузить» крупные файлы моделей в облако, и программа перестанет их читать.

```bash
mkdir -p ~/Projects
cd ~/Projects
git clone https://github.com/ambkar/Transcriber.git transcriber
cd transcriber
```

### Шаг 5. Виртуальное окружение и библиотеки

Окружение (venv) это отдельная папка с библиотеками только для этого проекта. Работать с программой нужно только внутри него.

```bash
/Library/Frameworks/Python.framework/Versions/3.13/bin/python3.13 -m venv venv
source venv/bin/activate
python --version
pip install --upgrade pip
pip install -r requirements.txt
```

После `source venv/bin/activate` в начале строки появится `(venv)`: значит, окружение включено. Команда `python --version` должна показать `Python 3.13.5`. Установка библиотек занимает несколько минут.

## Запуск

Каждый раз, когда вы открываете новое окно Терминала, выполняйте:

```bash
cd ~/Projects/transcriber
source venv/bin/activate
python app.py
```

Откроется браузер со страницей http://127.0.0.1:8000. Если не открылся, перейдите по этому адресу сами. Чтобы остановить программу, вернитесь в Терминал и нажмите `Ctrl + C`.

### Как пользоваться

1. Выберите режим: «Видео» или «Расшифровка созвона».
2. Укажите источник: вставьте ссылку или нажмите «Выбрать файл…» и найдите запись на компьютере.
3. Выберите профиль моделей. При первом выборе программа скачает модели, на странице будет виден прогресс.
4. Укажите количество спикеров, если знаете его, или оставьте «Определить автоматически».
5. По желанию впишите в поле «Термины и названия» слова, которые часто ошибочно распознаются: названия компаний, аббревиатуры, фамилии.
6. Нажмите «Начать». Полоса прогресса покажет текущий этап. Для первой проверки возьмите короткое видео на 3–5 минут.
7. Когда всё готово, результат появится на странице. Кнопка «Показать файл» откроет Finder с документом, а «Скачать DOCX» сохранит его.

За один раз программа обрабатывает одно видео.

## Обновление проекта

```bash
cd ~/Projects/transcriber

source venv/bin/activate

```

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| `brew: command not found` | Выполните три команды из конца шага 1 или откройте Терминал заново |
| Не скачивается видео с YouTube (ошибка 403) | Проверьте, что установлен deno (`deno --version`), и обновите загрузчик: `pip install -U "yt-dlp[default]"`. Если не помогло, скачайте видео вручную и загрузите как файл |
| Загрузка модели оборвалась (`IncompleteRead`, `Connection broken`) | Нажмите «Начать» ещё раз, загрузка продолжится |
| Ошибки `Unable to read 8 bytes` или `Protobuf parsing failed` при загрузке модели | Проект лежит в папке, которую синхронизирует iCloud. Перенесите его в `~/Projects`, удалите модели командой `rm -rf Models/asr Models/llm Models/diarization Models/.markers` и создайте окружение заново |
| Спикеров в расшифровке больше, чем в записи | Укажите точное число спикеров в форме вместо автоопределения |
| Кнопки на странице не работают после обновления | Обновите страницу с очисткой кэша: `Cmd + Shift + R` |
| `Address already in use` | Уже запущена другая копия программы. Закройте её через `Ctrl + C` в том Терминале |
| Не хватает памяти или Mac сильно тормозит | Выберите более лёгкий профиль |

Чтобы освободить место, модели можно удалить: `rm -rf Models/asr Models/llm Models/diarization Models/.markers`. При следующем запуске нужные модели скачаются заново.

## Ограничения

- Расшифровка не идеальна. Ошибки возможны в именах, терминах, аббревиатурах и в местах, где собеседники говорят одновременно.
- Саммари пишет нейросеть, поэтому его стоит проверять по тексту расшифровки. Лёгкий профиль ошибается чаще остальных.
- Имена спикеров определяются только если они прозвучали в разговоре, и могут быть найдены неверно.
- При большом числе похожих голосов автоматическое определение числа спикеров может ошибаться.

## Для разработчиков

Структура проекта:

```
transcriber/
├── app.py                 # запуск: FastAPI + браузер
├── requirements.txt
├── core/                  # общий код: модели, звук, спикеры, речь, анализ, DOCX
├── scenarios/             # video.py и meeting.py
├── templates/index.html   # страница (Jinja)
├── static/                # app.js, style.css
├── Models/  Work/  Final/ # создаются автоматически, в Git не попадают
└── venv/                  # окружение, в Git не попадает
```

Технологии: FastAPI, Jinja2, yt-dlp, ffmpeg, mlx-whisper, mlx-lm, sherpa-onnx, python-docx.
